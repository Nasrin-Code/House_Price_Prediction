# House Price Prediction

A machine learning project that predicts house values using numerical housing features and Linear Regression.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Linear Regression
- StandardScaler

## Dataset

This project uses the California Housing dataset provided by Scikit-learn.

- 20,640 samples
- 8 numerical features
- Target: `MedHouseVal`

## Features

- MedInc
- HouseAge
- AveRooms
- AveBedrms
- Population
- AveOccup
- Latitude
- Longitude

## Project Workflow

1. Load the California Housing dataset
2. Explore the dataset
3. Check for missing values
4. Standardize the input features
5. Split the data into training and testing sets
6. Train a Linear Regression model
7. Predict house values
8. Evaluate the model using Mean Squared Error (MSE)
